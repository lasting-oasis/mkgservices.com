# Service zones / Zonas de servicio

Five zones by ZIP code for the zone days in the Operations plan (Growth plans doc).
`zonas.csv` is the same list as the Zones tab in MKG Books; `mapa-zonas.png` is the
map in the owner's binder ("11 Zonas y días de zona").

Days: North and Northeast Monday, East Tuesday, South Wednesday, West Thursday;
Friday is the busiest day, for full-price clients from any zone. Zones are a
starting point drawn from geography (I-77, I-85, US-74, the Catawba River and the
state line); redraw them once real client addresses are in MKG Books.

Built Oct 24, 2026 from 2010 ZCTA boundaries (OpenDataDE/State-zip-code-GeoJSON).
